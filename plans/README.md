# Plans

Um plan traduz uma spec (`specs/`) em decisões técnicas: **como** construir.

## Convenção de nome

Mesmo número/nome da spec correspondente: `NNNN-nome-curto.md`.

## Template

```markdown
# NNNN - Título

Spec relacionada: `specs/NNNN-nome-curto.md`

## Stack / ferramentas
...

## Arquitetura
...

## Etapas
1. ...
2. ...

## Riscos / pontos de atenção
...
```
