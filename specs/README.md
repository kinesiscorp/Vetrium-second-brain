# Specs

Uma spec descreve **o que** construir e **por quê** — não o "como" (isso fica em `plans/`).

## Convenção de nome

`NNNN-nome-curto.md` (ex: `0001-landing-page-scaffold.md`), numeração sequencial.

## Template

```markdown
# NNNN - Título

## Contexto
Por que isso está sendo feito. Qual problema ou necessidade motiva.

## Objetivo
O que deve existir ao final, em uma frase.

## Escopo
O que está incluído.

## Fora de escopo
O que explicitamente não está incluído (evita ambiguidade).

## Critérios de aceite
- [ ] ...
- [ ] ...
```
