# 0003 - Referências de portfólio (substrato para a landing page da Vetrium)

## Contexto
Catálogo dos projetos anteriores do Gabriel Carvalho (sócio), reunidos como substrato visual/estratégico para a spec de design da landing page da própria Vetrium (ver `0001-landing-page-scaffold.md`) e para a futura seção de portfólio/cases do site. Fontes: PDF de portfólio (`Slide 16_9 - 1-exported-by-super-pdf_compressed.pdf`, na raiz do repo — não versionado) e arquivos Figma compartilhados.

> Este documento foi escrito quando a empresa ainda se chamava "Achievo" — mantido como registro histórico onde relevante. Ver `decisions/0002-renomeacao-para-vetrium.md`.

## Referência externa (modelo de negócio parecido)

### Insany (insany.com.br)
Agência de design & tecnologia com posicionamento quase idêntico ao da Achievo (produtos digitais, redesign, branding). Site de altíssima produção: seções full-bleed alternando escuro/claro, títulos de seção enormes com "." final (ex: "Serviços.", "Projetos."), peso misto dentro do próprio headline (parte preta/branca forte + parte cinza) para hierarquia, cases apresentados como mockup de tablet flutuando numa cena 3D colorida por marca, logos de clientes reais (Yampi, Unico, GitHub) para credibilidade, CTA em pill consistente.
**Takeaway:** ótima referência de **estrutura, confiança tipográfica e copy de posicionamento para agências B2B** — não de execução literal, já que os renders 3D customizados fogem do escopo "simples" que queremos para a primeira versão do nosso site. Ver `plans/0001-landing-page-scaffold.md` para como isso foi adaptado.

## ✅ Conflito de nome — RESOLVIDO (renomeado para Vetrium)

Um dos projetos do Gabriel Carvalho (Figma: `ACHIEVO`) usava exatamente o mesmo nome que a empresa tinha escolhido de início. A empresa foi renomeada para **Vetrium** justamente para evitar essa colisão — ver `decisions/0002-renomeacao-para-vetrium.md`. O projeto do portfólio abaixo permanece com o nome "Achievo" (é o nome dele mesmo, não da empresa) e continua valendo como referência de processo de design.

### Achievo (app) (Figma: `ACHIEVO`)
App de carreira/produtividade com relatórios semanais ("Weekly Report"). Logo: ícone line-art de alpaca/lhama + wordmark "Achievo°". Paleta: verde como primária (5 tons, de `primary/light` a `primary/900`) + laranja/terracota como secundária (4 tons) + cores semânticas padrão (vermelho/laranja/azul/verde) + escala de cinza própria. Tipografia Poppins. Userflow documentado: login → cadastro → home/dashboard → adicionar/editar/deletar relatório → relatório semanal. O arquivo compartilhado contém o design system completo (Style Guide, Documentation, Resources/Components), mas não as telas finais de alta fidelidade do app/LP/site — só o Cover as mostra, em mockup 3D isométrico.
**Takeaway:** é o processo de design mais maduro do portfólio (design system com semântica de cor documentada) — bom modelo de rigor a seguir nos próprios projetos da Achievo, independente do nome.

## Projetos

### Drawincad Studio — PDF, pág. 4 (⭐ referência principal indicada)
Estúdio de projetos 3D/arquitetura. Dark UI com um único acento verde-menta (`#41D48D`) sobre grafite (`#121F28`) — paleta contida, um acento só. Style guide documentado (cores + tipografia Sansation com pesos definidos). Case apresentado num diagrama de Venn "Resultados e Aprendizados" (Sistema de Componentes / Microinterações / Melhoria de Marca / Experiência em UI).
**Takeaway:** disciplina de um-acento-só + forma elegante de apresentar case (Venn) — ambos reaproveitáveis na seção de portfólio da Achievo.

### Startruck — PDF, pág. 5
Plataforma de logística/transporte. Segue a mesma linguagem de case do Drawincad (dark UI, case estruturado com resultados/aprendizados). Vale reabrir o PDF junto com o Gabriel Carvalho para extrair paleta/tipografia exatas antes de usar como referência de cor — não capturei os valores exatos aqui.

### Gatômetro (Figma: `Redesign - Gatômetro`)
Página de Foundations completa: paleta primária laranja/vermelho-rosa, secundária azul, tipografia Plus Jakarta Sans + Inter, grids desktop/mobile documentados. Página **Wireframe** própria com wireframe de Landing Page (desktop + mobile) e um mid-fi mockup: hero "Nunca pague mais caro", seção de recursos em 3 colunas, "Simples como 1, 2, 3" em passos, footer escuro.
**Takeaway:** processo completo e visível (foundations → wireframe → mid-fi) — bom modelo de como documentar o processo de design nos cases da Achievo.

### Memoryiit (Figma: `Redesign - Memoryiit`)
App de galeria de memórias/fotos para casais. Dark UI, logo com gradiente azul-verde (ícone de nuvem/memória). Tela de galeria em cards de fotos. Contém página de **Handoff - LP** dedicada (landing page de marketing separada das telas de app).
**Takeaway:** separar claramente "produto" (app) de "aquisição" (landing page) como páginas distintas no Figma — prática organizacional a adotar no nosso próprio fluxo de projeto.

### Kabra / Layerio (Figma: `Kabra`)
Landing page de SaaS de produtividade ("Layerio"). Dark hero, screenshots de app, seção de FAQ, footer "Say Hello to Layerio".
**Takeaway:** estrutura clássica de SaaS B2B — útil como referência de copy/hierarquia se a Achievo for pitchar produtos SaaS no futuro.

### Master Crypto® (Figma: `Master Crypto®`)
Marketplace de NFTs. Cover com ilustração isométrica 3D de um polvo mascote + telas de app flutuando no espaço. Landing page completa: hero com mascote + badges de app store, carrossel "Popular Artwork", leaderboard "Top Collectors", newsletter, FAQ. Paleta vibrante roxo/rosa/ciano sobre fundo escuro; fitas diagonais tipo "20% OFF".
**Takeaway:** o projeto mais ousado visualmente do portfólio — bom exemplo de ilustração 3D como elemento de hero, caso a Achievo queira um posicionamento mais "vitrine" para certos clientes.

### Cycleit (Figma: `Cycleit`)
App mobile de marketplace de economia circular (revenda/reuso de produtos). Verde-oliva como cor primária, cards brancos/crus, UI limpa e minimalista (onboarding, busca, grid de produtos, detalhe, pedidos com badges de status).
**Takeaway:** exemplo de app mobile-first bem executado, mais sóbrio que os outros — mostra range estilístico do Gabriel Carvalho (nem tudo é dark/neon).

### Aurevo (Figma: `AUREVO`) — branding, não é produto digital
Não é um app/site — é um board de gestão de conteúdo (feed do Instagram, TikTok, e-book, e-commerce) de uma marca de conteúdo fitness/autodesenvolvimento. Fundo escuro com acento verde, templates de post com tipografia serifada/script para citações motivacionais.
**Takeaway:** referência de branding de conteúdo (não de produto) — útil se a Achievo também for cuidar de redes sociais de clientes, não só sites.

## Padrão observado em todo o portfólio
Praticamente todos os projetos usam **fundo escuro + um único acento de cor saturado**, nunca múltiplos acentos competindo. É a assinatura visual mais consistente do Gabriel Carvalho — forte candidato a virar também a assinatura da própria Achievo.
