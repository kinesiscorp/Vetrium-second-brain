# 0002 - Renomeação de Achievo para Vetrium

Data: 2026-08-03
Status: Aceita

## Contexto
A empresa foi fundada como "Achievo". Durante o levantamento de referências de portfólio (`specs/0003-referencias-portfolio.md`), identificamos que já existe um projeto chamado "Achievo" no portfólio do Gabriel Carvalho (app de carreira/produtividade), o que gerava ambiguidade de marca.

## Decisão
Renomear a empresa para **Vetrium — Design & Technology**. Nova identidade visual: conceito de minério raro/metal misterioso (remete ao sufixo "-ium" de elementos químicos), tom azul levemente arroxeado, acabamento metálico.

## Consequências
- Resolve o conflito de nome sem precisar mexer no projeto Achievo (app) do portfólio.
- Pasta central do repositório renomeada de `achievo/` para `vetrium/`.
- Documentos históricos (`specs/0001` a `0003`) mantêm menções a "Achievo" onde isso registra contexto/decisões da época — não foram reescritos retroativamente.
- Novo trabalho (LP, branding, specs futuras) usa "Vetrium" a partir desta data.
