# Decisions

Registro de decisões relevantes que afetam mais de um projeto ou definem convenções da empresa (stack padrão, processo, estrutura de repos, etc). Formato inspirado em ADR (Architecture Decision Record).

## Convenção de nome

`NNNN-titulo-curto.md`, numeração sequencial.

## Template

```markdown
# NNNN - Título

Data: AAAA-MM-DD
Status: Proposta | Aceita | Substituída por NNNN

## Contexto
O que motivou a decisão.

## Decisão
O que foi decidido.

## Consequências
O que isso implica, positivo e negativo.
```
